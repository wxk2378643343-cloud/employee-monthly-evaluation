## 1. 项目概述

### 1.1 项目背景

为规范基层单位员工月度考核流程，建立科学、公正的评价体系，开发本员工月度评价系统。系统支持多维度、多主体的综合评价，并通过活水预警机制识别绩效待改进人员。

### 1.2 项目目标

- 实现员工月度评价的线上化、规范化管理
- 支持多维度（工作记录、重点指标、重点工作）评价
- 支持多主体（互评、小组长、分管领导、单位领导）评分
- **领导打分范围由管理员按周期、按小组灵活配置**
- 提供自动排名、预警提醒功能
- 集成钉钉实现消息推送

### 1.3 技术栈

| 层级 | 技术选型 | 版本 |
|------|----------|------|
| 前端框架 | React | 18.x |
| UI组件库 | Ant Design | 5.x |
| 状态管理 | Redux Toolkit | 1.9.x |
| 后端框架 | Spring Boot | 2.7.x |
| ORM框架 | MyBatis-Plus | 3.5.x |
| 数据库 | MySQL | 5.7+ |
| 缓存 | Redis | 6.x |
| 消息推送 | 钉钉开放平台 | - |

## 2. 需求分析

### 2.1 组织结构

系统采用 **部门 → 小组 → 员工** 三级组织结构：

```
单位（顶级）
├── 部门A
│   ├── 一组（小组长：赵组长）
│   │   ├── 员工A
│   │   ├── 员工B
│   │   └── 员工C
│   └── 二组（小组长：钱组长）
│       ├── 员工D
│       └── 员工E
└── 部门B
    ├── 三组
    └── 四组
```

- 每个员工归属一个小组，小组归属一个部门
- 员工互评范围为**同小组内**互评
- 领导（小组长/分管领导/单位领导）打分范围**由管理员按评价周期灵活配置**，不固定绑死

### 2.2 评价维度

| 维度 | 权重 | 说明 |
|------|------|------|
| 工作记录 | 20% | 日常工作完成情况 |
| 重点指标 | 60% | 核心KPI指标完成度 |
| 重点工作 | 20% | 重点任务完成情况 |

### 2.3 评价主体

| 主体 | 权重 | 说明 |
|------|------|------|
| 员工互评 | 30% | 同小组员工相互评价 |
| 小组长 | 20% | 小组长评价（按分配的小组） |
| 分管领导 | 20% | 分管领导评价（按分配的小组） |
| 单位领导 | 20% | 单位负责人评价（按分配的小组） |
| 线性排名 | 10% | 管理员手动设置（1-100分） |

### 2.4 打分分配机制

管理员在每个评价周期开始前，配置每位领导负责给哪些小组的员工打分。

**核心规则：**
- 同一个领导可以被分配多个小组
- 同一个小组可以被多个同类型领导打分（如两个分管领导都给一组打分）
- 每期可以调整，也可以从上期复制后微调
- 小组长默认只负责自己的小组，也可以由管理员额外分配其他小组

**示例配置：**

| 领导 | 角色 | 2024年1月负责小组 | 2024年2月负责小组 |
|------|------|------------------|------------------|
| 王总 | 单位领导 | 一组、二组、三组、四组 | 一组、二组、三组、四组 |
| 李副总 | 分管领导 | 一组、二组 | 一组、三组 |
| 张副总 | 分管领导 | 三组、四组 | 二组、四组 |
| 赵组长 | 小组长 | 一组 | 一组 |
| 钱组长 | 小组长 | 二组 | 二组 |

### 4.2 表结构设计

#### 4.2.1 部门表 (sys_department)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT | 是 | 主键 |
| parent_id | BIGINT | 否 | 上级部门ID，0表示顶级 |
| dept_name | VARCHAR(100) | 是 | 部门名称 |
| dept_code | VARCHAR(50) | 否 | 部门编码 |
| leader_id | BIGINT | 否 | 部门负责人ID |
| sort_order | INT | 否 | 排序号 |
| status | TINYINT | 是 | 状态：1启用 0禁用 |
| create_time | DATETIME | 是 | 创建时间 |
| update_time | DATETIME | 是 | 更新时间 |

```sql
CREATE TABLE sys_department (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键',
    parent_id BIGINT DEFAULT 0 COMMENT '上级部门ID',
    dept_name VARCHAR(100) NOT NULL COMMENT '部门名称',
    dept_code VARCHAR(50) COMMENT '部门编码',
    leader_id BIGINT COMMENT '部门负责人ID',
    sort_order INT DEFAULT 0 COMMENT '排序号',
    status TINYINT DEFAULT 1 COMMENT '状态：1启用 0禁用',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_parent_id (parent_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='部门表';
```

```java
@Service
public class AssignService {

    @Autowired
    private EvalScoreAssignMapper assignMapper;

    @Autowired
    private SysGroupMapper groupMapper;

    /**
     * 保存打分分配配置
     */
    @Transactional
    public void saveAssignments(Long periodId, List<AssignDTO> assignments) {
        // 先删除该周期的旧配置
        assignMapper.delete(
            new LambdaQueryWrapper<EvalScoreAssign>()
                .eq(EvalScoreAssign::getPeriodId, periodId)
        );

        // 批量插入新配置
        List<EvalScoreAssign> records = new ArrayList<>();
        for (AssignDTO dto : assignments) {
            for (Long groupId : dto.getGroupIds()) {
                EvalScoreAssign assign = new EvalScoreAssign();
                assign.setPeriodId(periodId);
                assign.setEvaluatorId(dto.getEvaluatorId());
                assign.setEvaluatorType(dto.getEvaluatorType());
                assign.setGroupId(groupId);
                records.add(assign);
            }
        }
        if (!records.isEmpty()) {
            assignMapper.insertBatch(records);
        }
    }

    /**
     * 从上期复制分配方案
     */
    @Transactional
    public void copyFromPrevious(Long sourcePeriodId, Long targetPeriodId) {
        List<EvalScoreAssign> sourceList = assignMapper.selectList(
            new LambdaQueryWrapper<EvalScoreAssign>()
                .eq(EvalScoreAssign::getPeriodId, sourcePeriodId)
        );

        if (sourceList.isEmpty()) {
            throw new BusinessException("源周期无分配数据");
        }

        // 删除目标周期旧数据
        assignMapper.delete(
            new LambdaQueryWrapper<EvalScoreAssign>()
                .eq(EvalScoreAssign::getPeriodId, targetPeriodId)
        );

        // 复制并插入
        List<EvalScoreAssign> targetList = sourceList.stream().map(s -> {
            EvalScoreAssign t = new EvalScoreAssign();
            t.setPeriodId(targetPeriodId);
            t.setEvaluatorId(s.getEvaluatorId());
            t.setEvaluatorType(s.getEvaluatorType());
            t.setGroupId(s.getGroupId());
            return t;
        }).collect(Collectors.toList());

        assignMapper.insertBatch(targetList);
    }

    /**
     * 获取某周期的分配列表（按领导聚合）
     */
    public List<AssignVO> getAssignList(Long periodId) {
        List<EvalScoreAssign> assigns = assignMapper.selectList(
            new LambdaQueryWrapper<EvalScoreAssign>()
                .eq(EvalScoreAssign::getPeriodId, periodId)
        );

        // 按评价人聚合
        Map<Long, List<EvalScoreAssign>> grouped = assigns.stream()
            .collect(Collectors.groupingBy(EvalScoreAssign::getEvaluatorId));

        List<AssignVO> result = new ArrayList<>();
        for (Map.Entry<Long, List<EvalScoreAssign>> entry : grouped.entrySet()) {
            AssignVO vo = new AssignVO();
            vo.setEvaluatorId(entry.getKey());
            vo.setEvaluatorType(entry.getValue().get(0).getEvaluatorType());
            vo.setGroupIds(entry.getValue().stream()
                .map(EvalScoreAssign::getGroupId)
                .collect(Collectors.toList()));
            result.add(vo);
        }
        return result;
    }
}
```

### 5.2 打分模块

#### 5.2.1 功能说明

- 员工互评：同小组内员工相互评价
- 领导评分：根据打分分配表，获取待评价员工列表并打分
- 自动计算综合得分
- 第二轮投票表决

#### 5.2.2 评分计算规则

**维度权重（每条评分明细内部计算）：**
```
维度得分 = 工作记录分 × 20% + 重点指标分 × 60% + 重点工作分 × 20%
```

**综合得分（汇总所有主体）：**
```
综合得分 = 互评均分 × 30% + 小组长均分 × 20% + 分管领导均分 × 20% + 单位领导均分 × 20% + 线性排名分 × 10%
```

> 注：如果某主体有多人打分（如两个分管领导都给一个员工打分），取该类型所有打分的均值。

**线性排名分：**
```
线性排名分 = 管理员手动设置（1-100分）
```

> 线性排名分由管理员在第一轮评价结束后、系统计算综合得分前，为每位员工手动录入。管理员可根据实际业务情况灵活打分，不再由系统自动计算。

```java
@Service
public class ScoreService {

    /**
     * 获取待评价人员列表
     * - 普通员工/小组长身份互评：返回同小组的同事
     * - 领导身份打分：返回本期分配的小组下的员工
     */
    public List<PendingUserVO> getPendingList(Long currentUserId, Long periodId) {
        SysUser currentUser = userMapper.selectById(currentUserId);
        List<PendingUserVO> result = new ArrayList<>();

        // 1. 互评部分（角色1员工、角色2小组长都要参与互评）
        if (currentUser.getRoleType() <= 2 && currentUser.getGroupId() != null) {
            List<SysUser> peers = userMapper.selectList(
                new LambdaQueryWrapper<SysUser>()
                    .eq(SysUser::getGroupId, currentUser.getGroupId())
                    .eq(SysUser::getStatus, 1)
                    .ne(SysUser::getId, currentUserId)
            );
            for (SysUser peer : peers) {
                PendingUserVO vo = buildPendingVO(peer, "互评");
                vo.setScored(hasScored(periodId, currentUserId, peer.getId()));
                result.add(vo);
            }
        }

        // 2. 领导打分部分（角色2/3/4根据分配表查询）
        if (currentUser.getRoleType() >= 2 && currentUser.getRoleType() <= 4) {
            List<EvalScoreAssign> assigns = assignMapper.selectList(
                new LambdaQueryWrapper<EvalScoreAssign>()
                    .eq(EvalScoreAssign::getPeriodId, periodId)
                    .eq(EvalScoreAssign::getEvaluatorId, currentUserId)
            );

            if (!assigns.isEmpty()) {
                List<Long> groupIds = assigns.stream()
                    .map(EvalScoreAssign::getGroupId)
                    .collect(Collectors.toList());

                List<SysUser> targets = userMapper.selectList(
                    new LambdaQueryWrapper<SysUser>()
                        .in(SysUser::getGroupId, groupIds)
                        .eq(SysUser::getStatus, 1)
                        .ne(SysUser::getId, currentUserId)
                );

                String roleLabel = getRoleLabel(currentUser.getRoleType());
                for (SysUser target : targets) {
                    PendingUserVO vo = buildPendingVO(target, roleLabel);
                    vo.setScored(hasScored(periodId, currentUserId, target.getId()));
                    result.add(vo);
                }
            }
        }

        return result;
    }

    /**
     * 提交评分
     */
    @Transactional
    public void submitScore(Long evaluatorId, ScoreSubmitDTO dto) {
        SysUser evaluator = userMapper.selectById(evaluatorId);
        Long periodId = dto.getPeriodId();
        Long targetUserId = dto.getTargetUserId();

        // 确定评价类型
        int evaluatorType = determineEvaluatorType(evaluator, targetUserId, periodId);

        // 权限校验
        checkScorePermission(evaluatorId, targetUserId, periodId, evaluatorType);

        // 保存明细
        EvalDetail detail = new EvalDetail();
        detail.setPeriodId(periodId);
        detail.setEvaluatorId(evaluatorId);
        detail.setTargetUserId(targetUserId);
        detail.setEvaluatorType(evaluatorType);
        detail.setWorkRecordScore(dto.getWorkRecordScore());
        detail.setKeyIndicatorScore(dto.getKeyIndicatorScore());
        detail.setKeyWorkScore(dto.getKeyWorkScore());
        detail.setComment(dto.getComment());
        evalDetailMapper.insert(detail);
    }

    /**
     * 判断评价人类型
     * - 如果评价人和被评价人在同一小组且角色<=2，视为互评
     * - 否则根据分配表判断是小组长/分管领导/单位领导打分
     */
    private int determineEvaluatorType(SysUser evaluator, Long targetUserId, Long periodId) {
        SysUser target = userMapper.selectById(targetUserId);

        // 同小组互评
        if (evaluator.getGroupId() != null
            && evaluator.getGroupId().equals(target.getGroupId())
            && evaluator.getRoleType() <= 2) {
            return 1;
        }

        // 领导打分：返回对应的角色类型
        return evaluator.getRoleType();
    }

    /**
     * 校验打分权限
     */
    private void checkScorePermission(Long evaluatorId, Long targetUserId,
                                       Long periodId, int evaluatorType) {
        if (evaluatorType == 1) {
            // 互评：校验同小组
            SysUser evaluator = userMapper.selectById(evaluatorId);
            SysUser target = userMapper.selectById(targetUserId);
            if (!evaluator.getGroupId().equals(target.getGroupId())) {
                throw new BusinessException("互评仅限同小组");
            }
            return;
        }

        // 领导打分：校验分配表
        SysUser target = userMapper.selectById(targetUserId);
        long count = assignMapper.selectCount(
            new LambdaQueryWrapper<EvalScoreAssign>()
                .eq(EvalScoreAssign::getPeriodId, periodId)
                .eq(EvalScoreAssign::getEvaluatorId, evaluatorId)
                .eq(EvalScoreAssign::getGroupId, target.getGroupId())
        );
        if (count == 0) {
            throw new BusinessException("您未被分配评价该员工，无权打分");
        }
    }
}
```

#### 5.2.4 评分计算

```java
@Service
public class ScoreCalculateService {

    // 维度权重
    private static final double WORK_RECORD_WEIGHT = 0.20;
    private static final double KEY_INDICATOR_WEIGHT = 0.60;
    private static final double KEY_WORK_WEIGHT = 0.20;

    // 主体权重
    private static final double PEER_WEIGHT = 0.30;
    private static final double TEAM_LEADER_WEIGHT = 0.20;
    private static final double SUPERVISOR_WEIGHT = 0.20;
    private static final double UNIT_LEADER_WEIGHT = 0.20;
    private static final double LINEAR_RANK_WEIGHT = 0.10;

    /**
     * 计算员工综合得分
     */
    @Transactional
    public void calculateTotalScore(Long periodId, Long targetUserId) {
        EvalRecord record = getOrCreateRecord(periodId, targetUserId);

        // 计算各主体得分（维度加权后取均分）
        double peerScore = calcAvgScoreByType(periodId, targetUserId, 1);
        double teamLeaderScore = calcAvgScoreByType(periodId, targetUserId, 2);
        double supervisorScore = calcAvgScoreByType(periodId, targetUserId, 3);
        double unitLeaderScore = calcAvgScoreByType(periodId, targetUserId, 4);

        record.setPeerScore(BigDecimal.valueOf(peerScore));
        record.setTeamLeaderScore(BigDecimal.valueOf(teamLeaderScore));
        record.setSupervisorScore(BigDecimal.valueOf(supervisorScore));
        record.setUnitLeaderScore(BigDecimal.valueOf(unitLeaderScore));

        // 计算总分（不含线性排名，用于排序）
        double totalWithoutRank = peerScore * PEER_WEIGHT
            + teamLeaderScore * TEAM_LEADER_WEIGHT
            + supervisorScore * SUPERVISOR_WEIGHT
            + unitLeaderScore * UNIT_LEADER_WEIGHT;

        record.setTotalScore(BigDecimal.valueOf(totalWithoutRank));
        evalRecordMapper.updateById(record);
    }

    /**
     * 按评价人类型计算维度加权均分
     * 支持同一类型多人打分（如多个分管领导），取均值
     */
    private double calcAvgScoreByType(Long periodId, Long targetUserId, int evaluatorType) {
        List<EvalDetail> details = evalDetailMapper.selectList(
            new LambdaQueryWrapper<EvalDetail>()
                .eq(EvalDetail::getPeriodId, periodId)
                .eq(EvalDetail::getTargetUserId, targetUserId)
                .eq(EvalDetail::getEvaluatorType, evaluatorType)
        );

        if (details.isEmpty()) return 0;

        return details.stream()
            .mapToDouble(this::calcDimensionScore)
            .average()
            .orElse(0);
    }

    /**
     * 计算单条评价的维度加权分
     */
    private double calcDimensionScore(EvalDetail detail) {
        return detail.getWorkRecordScore().doubleValue() * WORK_RECORD_WEIGHT
            + detail.getKeyIndicatorScore().doubleValue() * KEY_INDICATOR_WEIGHT
            + detail.getKeyWorkScore().doubleValue() * KEY_WORK_WEIGHT;
    }

    /**
     * 计算最终总分（含管理员设置的线性排名分）并排名
     *
     * 调用时机：管理员设置完线性排名分后，触发最终计算
     * 线性排名分已由管理员提前录入到 eval_record.linear_rank_score
     */
    @Transactional
    public void calculateFinalScoreAndRank(Long periodId, Long deptId) {
        List<EvalRecord> records = evalRecordMapper.selectList(
            new LambdaQueryWrapper<EvalRecord>()
                .eq(EvalRecord::getPeriodId, periodId)
                .eq(EvalRecord::getDeptId, deptId)
        );

        // 1. 计算每人最终总分（含管理员设置的线性排名分）
        for (EvalRecord record : records) {
            double linearScore = record.getLinearRankScore().doubleValue(); // 管理员已设置
            double finalTotal = record.getPeerScore().doubleValue() * PEER_WEIGHT
                + record.getTeamLeaderScore().doubleValue() * TEAM_LEADER_WEIGHT
                + record.getSupervisorScore().doubleValue() * SUPERVISOR_WEIGHT
                + record.getUnitLeaderScore().doubleValue() * UNIT_LEADER_WEIGHT
                + linearScore * LINEAR_RANK_WEIGHT;
            record.setTotalScore(BigDecimal.valueOf(finalTotal));
        }

        // 2. 按总分降序排名
        records.sort((a, b) -> b.getTotalScore().compareTo(a.getTotalScore()));

        int total = records.size();
        int bottomCount = Math.max(1, (int) Math.ceil(total * 0.03));

        for (int i = 0; i < records.size(); i++) {
            EvalRecord record = records.get(i);
            int rank = i + 1;
            record.setDeptRank(rank);

            // 标记后3%（部门人数不足5人时不标记）
            if (total >= 5 && rank > total - bottomCount) {
                record.setIsBottom(1);
            }

            evalRecordMapper.updateById(record);
        }
    }
}
```

截止提醒需要知道谁还没评完。基于分配表计算：

```java
@Service
public class RemindService {

    /**
     * 发送截止提醒给未完成评价的人
     */
    public void sendDeadlineRemind(Long periodId, int daysLeft) {
        // 1. 查询所有需要打分的领导及其应评人数
        List<EvalScoreAssign> allAssigns = assignMapper.selectList(
            new LambdaQueryWrapper<EvalScoreAssign>()
                .eq(EvalScoreAssign::getPeriodId, periodId)
        );

        Map<Long, List<Long>> evaluatorToGroups = allAssigns.stream()
            .collect(Collectors.groupingBy(
                EvalScoreAssign::getEvaluatorId,
                Collectors.mapping(EvalScoreAssign::getGroupId, Collectors.toList())
            ));

        for (Map.Entry<Long, List<Long>> entry : evaluatorToGroups.entrySet()) {
            Long evaluatorId = entry.getKey();
            List<Long> groupIds = entry.getValue();

            // 应评人数
            int shouldScore = userMapper.selectCount(
                new LambdaQueryWrapper<SysUser>()
                    .in(SysUser::getGroupId, groupIds)
                    .eq(SysUser::getStatus, 1)
                    .ne(SysUser::getId, evaluatorId)
            );

            // 已评人数
            int alreadyScored = evalDetailMapper.selectCount(
                new LambdaQueryWrapper<EvalDetail>()
                    .eq(EvalDetail::getPeriodId, periodId)
                    .eq(EvalDetail::getEvaluatorId, evaluatorId)
                    .ne(EvalDetail::getEvaluatorType, 1) // 排除互评
            );

            int remaining = shouldScore - alreadyScored;
            if (remaining > 0) {
                sendRemind(periodId, evaluatorId, 2,
                    String.format("评价将于%d天后截止，您还有%d人未评，请尽快完成", daysLeft, remaining));
            }
        }

        // 2. 查询所有需要互评的员工
        sendPeerDeadlineRemind(periodId, daysLeft);
    }
}
```

### 8.3 钉钉服务实现

```java
@Slf4j
@Service
public class DingTalkService {

    @Autowired
    private DingTalkConfig config;

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    @Autowired
    private RestTemplate restTemplate;  // 通过Bean注入复用

    private static final String TOKEN_KEY = "dingtalk:access_token";
    private static final String API_BASE = "https://oapi.dingtalk.com";

    /**
     * 获取 access_token（带缓存）
     */
    public String getAccessToken() {
        String token = redisTemplate.opsForValue().get(TOKEN_KEY);
        if (StringUtils.isNotBlank(token)) {
            return token;
        }

        String url = API_BASE + "/gettoken?appkey=" + config.getAppKey()
                   + "&appsecret=" + config.getAppSecret();

        Map<String, Object> result = restTemplate.getForObject(url, Map.class);

        if (result != null && Integer.valueOf(0).equals(result.get("errcode"))) {
            token = (String) result.get("access_token");
            redisTemplate.opsForValue().set(TOKEN_KEY, token, 7000, TimeUnit.SECONDS);
            return token;
        }

        log.error("获取钉钉token失败: {}", result);
        throw new RuntimeException("获取钉钉token失败");
    }

    /**
     * 发送工作通知
     */
    public void sendWorkNotice(String userId, String title, String content, String url) {
        if (!config.getEnabled()) {
            return;
        }

        String accessToken = getAccessToken();
        String apiUrl = API_BASE + "/topapi/message/corpconversation/asyncsend_v2?access_token=" + accessToken;

        Map<String, Object> msg = new HashMap<>();
        msg.put("agent_id", config.getAgentId());
        msg.put("userid_list", userId);
        msg.put("msg", buildLinkMsg(title, content, url));

        Map<String, Object> result = restTemplate.postForObject(apiUrl, msg, Map.class);

        if (result == null || !Integer.valueOf(0).equals(result.get("errcode"))) {
            log.error("钉钉消息发送失败: {}", result);
        }
    }

    /**
     * 批量发送（钉钉限制单次最多100人）
     */
    public void sendWorkNoticeBatch(List<String> userIds, String title, String content, String url) {
        if (!config.getEnabled() || userIds.isEmpty()) {
            return;
        }

        List<List<String>> batches = Lists.partition(userIds, 100);
        for (List<String> batch : batches) {
            String accessToken = getAccessToken();
            String apiUrl = API_BASE + "/topapi/message/corpconversation/asyncsend_v2?access_token=" + accessToken;

            Map<String, Object> msg = new HashMap<>();
            msg.put("agent_id", config.getAgentId());
            msg.put("userid_list", String.join(",", batch));
            msg.put("msg", buildLinkMsg(title, content, url));

            restTemplate.postForObject(apiUrl, msg, Map.class);
        }
    }

    private Map<String, Object> buildLinkMsg(String title, String content, String url) {
        Map<String, Object> msg = new HashMap<>();
        msg.put("msgtype", "link");

        Map<String, String> link = new HashMap<>();
        link.put("title", title);
        link.put("text", content);
        link.put("messageUrl", url);
        link.put("picUrl", "");

        msg.put("link", link);
        return msg;
    }
}
```

### 10.2 评分示例

**场景：** 员工A（属于技术部一组）收到以下评分

| 评价人 | 类型 | 工作记录 | 重点指标 | 重点工作 |
|--------|------|----------|----------|----------|
| 员工B（一组） | 互评 | 85 | 90 | 88 |
| 员工C（一组） | 互评 | 80 | 85 | 82 |
| 员工D（一组） | 互评 | 88 | 92 | 90 |
| 赵组长 | 小组长 | 85 | 88 | 86 |
| 李副总 | 分管领导 | 82 | 85 | 84 |
| 王总 | 单位领导 | 80 | 82 | 80 |

**计算过程：**

1. 员工B维度分 = 85×0.2 + 90×0.6 + 88×0.2 = 88.6
2. 员工C维度分 = 80×0.2 + 85×0.6 + 82×0.2 = 83.4
3. 员工D维度分 = 88×0.2 + 92×0.6 + 90×0.2 = 90.8
4. 互评均分 = (88.6 + 83.4 + 90.8) / 3 = 87.6
5. 小组长分 = 85×0.2 + 88×0.6 + 86×0.2 = 87.0
6. 分管领导分 = 82×0.2 + 85×0.6 + 84×0.2 = 84.2
7. 单位领导分 = 80×0.2 + 82×0.6 + 80×0.2 = 81.2
8. 线性排名分 = 75（管理员手动设置）

**综合得分：**
```
= 87.6×0.3 + 87.0×0.2 + 84.2×0.2 + 81.2×0.2 + 75×0.1
= 26.28 + 17.4 + 16.84 + 16.24 + 7.5
= 84.26分
```
